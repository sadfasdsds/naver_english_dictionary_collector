# Naver English Dictionary Collector

## Overview
A C# console application for collecting English words and meanings from the Naver English Dictionary.

## Tech Stack
- **Language:** C# (.NET 8.0)
- **Entry Point:** `collector.cs`
- **Project File:** `naver_english_dictionary_collector.csproj`

## Running the Project
The workflow "Start application" runs `dotnet run` to build and execute the project.

## Project Structure
- `collector.cs` — Main program entry point
- `naver_english_dictionary_collector.csproj` — .NET project configuration
- `README.md` — Project description
